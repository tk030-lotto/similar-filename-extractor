# 類似ファイル名抽出ツール（similar-filename-extractor）

フォルダの中の「似た名前のファイル」を探して、グループで一覧にする Web ツールです。

`report.pdf` と `report (1).pdf`、`企画書.docx` と `企画書_最終版.docx` のように、コピーや版の違いで増えてしまったファイルに気づくために使います。ファイル整理の前に、まず「どれとどれが似ているか」を目で確認する道具です。

## こんなときに

- フォルダ内に、コピーや日付・版数違いの似たファイルが増えて整理したいとき
- ファイルを削除・移動する前に、似た名前同士を並べて確認したいとき

## 主な機能

- フォルダを選ぶと、そのフォルダ以下にあるファイルの名前から、似ている名前同士をグループにして表示します
- ファイル名のリストを貼り付ける、または名前が書かれたテキストファイルを読み込んで調べることもできます
- グループごとに、7種類の違いの種類（コピー表記／版表記／日付／数字／拡張子／表記ゆれ／パスの違い）を表示します
- 結果の一覧は、テキストファイルとして保存したり、コピーしたりできます

## 使い方

1. [ツールを開く](https://zero-dev.jp/similar-filename-extractor/) をクリックします。
2. 「1. ファイル名を取り込む」で、「フォルダ選択」「貼り付け」「名前リスト読込」のどれかを選びます。
3. 選んだ方法に合わせてファイル名を取り込みます。
   - 「フォルダ選択」: 「フォルダを選択...」を押して、調べたいフォルダを選びます。
   - 「貼り付け」: 入力欄に、1行に1件ずつファイル名を貼り付けます。
   - 「名前リスト読込」: 「.txt / .csv ファイルを選択...」を押して、名前の一覧ファイルを選びます。
4. 「2. 取り込み一覧と抽出」にファイル名が表示されたら、「抽出する」を押します。
5. 「3. 抽出結果」に、似ている名前のグループが一覧で表示されます。
6. 必要なら、「結果をコピー」または「テキスト保存 (.txt)」を押して結果を取り出します。やり直すときは「クリア」を押します。

## うまくいかないとき

- 「フォルダ選択」が使えない環境・ブラウザのとき: 「貼り付け」または「名前リスト読込」をご利用ください。
- 名前リストファイルの読み込みでエラーが出るとき: `.txt` または `.csv` 形式（10MB 以下、文字コード UTF-8 または Shift-JIS、空でないファイル）を選択してください。
- 類似グループが 0件になるとき: 対象ファイル名が 1件以下、または日付のみなど付記の除去後に名前が空になり「キー対象外」になっている可能性があります。

## 動作環境

- 最近のブラウザ（Chrome、Edge、Firefox、Safari 16.4 以降）で動作します（後読み正規表現を使用しているため、Safari 16.4 未満では動作しません）

## 制限・注意

- **ファイルの中身は読みません。** フォルダを選んだ場合も、使うのはファイル名と場所（相対パス）だけで、ファイル本体は開きません
- **削除・移動・名前の変更はしません。** このツールは「似ているものを見つけて見せる」だけです。消すかどうかは、ご自身で確認して決めてください
- 入力したファイル名はブラウザの保存領域に保存されません（ページを閉じると消えます）
- 名前の形だけで判定するため、中身が同じかどうかは分かりません。また、「請求書_10月.pdf」と「請求書_11月.pdf」のように、数字だけが違う別のファイルも同じグループに出てきます。別物かどうかは、名前を見て判断してください
- 取り込めるファイル名は上限 10,000件です。上限を超えた場合は、超過分を取り込まずに打ち切り、その件数を画面に通知します
- 名前リスト読込で扱えるファイルは `.txt` / `.csv` 形式（サイズ 10MB 以下、UTF-8 / Shift-JIS）です。空ファイルや文字コードを判定できないファイルはエラーになり、それまでの取り込み一覧が保持されます
- 類似するファイル名が見つからずグループが0件だった場合は、「類似するファイル名は見つかりませんでした。」と表示されます
- 日付だけのファイル名など、付記の除去後に本体が空になる名前は「キー対象外」として扱い、類似グループには入れません

## 外部通信

- 外部サーバーへの通信は行いません。入力したファイル名はブラウザ内だけで処理され、外部へ送信されません（フッターの `zero-dev.jp` リンクのみ、クリック時にポータルサイトへ移動します）。
